SEMANTICA

Notacion matematica para las definiciones de mi bbdd:

Document (Un documento es un conjunto finito de pares (FieldName, Value)):
Document ⊆ FieldName × Value
d ∈ Document

Collection (Una colección es una lista de documentos.):
Collection = [Document]
C ∈ Collection

base de datos (Una base de datos es un conjunto finito de pares (CollectionName, Collection)):
Database ⊆ CollectionName × Collection
DB ∈ Database

Con todo eso definido podemos hacer:  " DB(col) = docs "
