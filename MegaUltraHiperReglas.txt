TS, VWS = efectos externos/laterales

:  ← Este operador nos sirve para indicar de que tipo es un Value
:! ← Este operador nos indica que el Value no es del tipo especificado

viewRead(v) ← Método que toma el nombre de la vista, la busca en el archivo que almacena las vistas y devuelve el Find correspondiente a ésta, donde Find contiene la coleccion a la que se le va a realizar la query, el conjunto de operaciones que se va a realizar sobre ésta y el terminal, que puede ser salida por pantalla o escritura en archivo

viewWrite(v, f) ← Método que toma el nombre de  vista, el Find que va a almacenar, al cual contiene la coleccion a la que se le va a realizar la query, el conjunto de operaciones que se va a realizar sobre ésta y el terminal, que puede ser salida por pantalla o escritura en archivo y lo escribe en el archivo que almacena las vistas

evalTerminal(qt, docs) ← Metodo que toma un queryTerminal y un listado de documentos. Dependiendo del queryTerminal, si es Preview produce una salida donde se mostraran los documentos por terminal, o si es Save se prioduce una salida donde se escribiran los documentos en el archivo especificado

desencapsulador(Value)  ← Método que permite desempaquetar el valor almacenado dentro de cada instancia de Value.

append ← Método que toma una colección, un objeto y devuelve la colección actualizada con el objeto agregado.

delete(cn) ← Método que toma el nombre de una colección y devuelve un nuevo estado sin la colección asociada a cn.

firstDoc(docs) ← Método que toma un lista de documentos, y devuelve solamente el primero de ellos.

lastsDocs(docs) ← Método que toma un lista de documentos y devuelve todos menos el primero.

merge(doc1, doc2) ← El método merge recibe dos documentos doc1 y doc2, y devuelve una copia actualizada de doc1 en la que los valores de las propiedades comunes con doc2 se sobrescriben con los de doc2, y las propiedades presentes únicamente en doc2 se agregan al resultado.

cn ∉ dom(σ) ← usamos el no pertenece para saber si existe o no una colección en la db

select(fields, d) ← devuelve el documento formado únicamente por los campos de d cuyos nombres pertenecen a fields

take(n, docs) ← devuelve los primeros n documentos de docs (si hay menos de n, devuelve todos)

sort(fields, docs) ← devuelve docs ordenados lexicográficamente según la secuencia de campos indicada en fields,
respetando para cada campo su dirección(Asc o Desc). Si un campo no está presente en alguno de los documentos comparados, se continúa con el siguiente criterio de orden.

El sort devuelve una lista de documentos tal que cada documento está correctamente ordenado respecto del siguiente según los criterios definidos en fields.


───────reglas de comparacion───────


───────────────────────── (Sort-Compare-Empty) si no hay mas criterios
d₁ ≤[] d₂


lookup(f, d₁) = v₁   lookup(f, d₂) = v₂   v₁ < v₂
───────────────────────────────────────────────────────────── (Sort-Compare-Asc) orden ascendente
d₁ ≤((f, Asc) : rest) d₂


lookup(f, d₁) = v₁   lookup(f, d₂) = v₂   v₁ > v₂
───────────────────────────────────────────────────────────── (Sort-Compare-Desc) caso descendente
d₁ ≤((f, Desc) : rest) d₂


lookup(f, d₁) = v   lookup(f, d₂) = v   d₁ ≤rest d₂
───────────────────────────────────────────────────────────── (Sort-Compare-Eq)igualdad, sigue con el sig criterio
d₁ ≤((f, ord) : rest) d₂
